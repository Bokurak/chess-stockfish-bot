# ♟️ Шахматный БОТ со Stockfish для Chess.com 🤖

Автоматический бот для Chess.com с движком Stockfish максимального уровня сложности (ELO 3200). Бот анализирует ходы и рассчитывает лучшие ходы за 1-2 секунды.

## 🎯 Возможности

- ✅ Автоматический анализ позиций
- ✅ Stockfish ELO 3200 (максимальная сложность)
- ✅ Время на ход: ~2 секунды
- ✅ Определение блестящих и замечательных ходов
- ✅ Анализ позиций
- ✅ Логирование всех ходов
- ✅ Поддержка Android (Termux)

## 📱 БЫСТРАЯ УСТАНОВКА

### Шаг 1: Termux
1. Установите **Termux** из F-Droid
2. Откройте Termux

### Шаг 2: Установка
```bash
pkg install python stockfish git -y
git clone https://github.com/Bokurak/chess-stockfish-bot.git
cd chess-stockfish-bot
pip install -r requirements.txt
```

### Шаг 3: Тест
```bash
python quick_start.py
```

### Шаг 4: Запуск
```bash
python chess_bot.py
```

## 📊 Использование

```bash
# Основной бот
python chess_bot.py

# Быстрая демонстрация
python quick_start.py
```

## 📋 Меню бота

После запуска `python chess_bot.py` вы увидите:

```
1. Анализировать стартовую позицию
2. Получить лучший ход для белых
3. Анализировать позицию (введите FEN)
4. Выход
```

Выберите опцию, введя цифру и нажав **Enter**.

## ⚙️ Параметры Stockfish

**Уровни ELO:**
- `800` - Beginner
- `1200` - Amateur
- `1600` - Intermediate
- `2000` - Advanced
- `2400` - Master
- `3200` - Super Computer (МАКСИМУМ)

**Текущие настройки:**
- ELO: 3200 (максимум)
- Глубина: 20 полуходов
- Время на ход: 2000 мс (2 секунды)
